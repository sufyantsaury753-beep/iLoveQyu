# iLoveQyu 📄❤️

> **Fast, private, and effortless PDF tools right in your browser.**  
> Dibuat oleh **Sufyan Tsaury**.

**iLoveQyu** adalah aplikasi web utilitas pengolahan dokumen PDF berbasis *100% Client-Side* (diproses langsung di memori browser pengguna tanpa pernah diunggah ke server luar).

## 🚀 Fitur Utama
* 📑 **Merge PDF:** Gabungkan beberapa file PDF menjadi satu dokumen utuh dengan fitur penataan urutan.
* ✂️ **Split PDF:** Ekstrak atau pisahkan halaman tertentu (misalnya: `1-3, 5`).
* 🔄 **Rotate PDF:** Putar orientasi halaman dokumen 90°, 180°, atau 270°.
* 🔏 **Watermark PDF:** Tambahkan tanda cap atau stempel teks dengan kontrol transparansi dan ukuran font.
* 🖼️ **JPG / PNG ke PDF:** Konversi file gambar menjadi dokumen PDF.
* ✂️ **Ekstrak & Hapus Halaman:** Buang halaman yang tidak diperlukan secara instan.

## 🔒 Privasi & Keamanan
* **Zero Server Uploads:** Seluruh manipulasi dokumen diproses menggunakan JavaScript & WebAssembly di dalam perangkat Anda.
* **Kecepatan Instan:** Performa pemrosesan lokal secepat perangkat keras Anda.
* **Gratis & Tanpa Batasan Kuota:** Tanpa antrean, tanpa watermark paksaan.

## 🛠️ Tech Stack
* **Framework:** React + Vite + TypeScript
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **PDF Processing Engine:** `pdf-lib`

## 💻 Cara Menjalankan Secara Lokal
```bash
# Clone repository
git clone https://github.com/sufyantsaury753-beep/iLoveQyu.git

# Masuk ke folder proyek
cd iLoveQyu

# Pasang dependensi
npm install

# Jalankan server pengembangan
npm run dev
```
